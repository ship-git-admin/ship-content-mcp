# 管理者向けの手順

## 1. 入れる

1. 公式の「MCP Adapter」（WordPress.org）と、このプラグインを入れて有効にする。**このプラグインを先に有効にする**と、公式の既定サーバーができない（既定サーバーは、公開の印の付いたほかの Ability を出すことがある）。
2. 「設定 → Ship Content MCP → 診断」で、問題（赤）がないか確かめる。各項目に「対処」が出る。
3. REST を止めるコード（セキュリティの Snippet など）があるサイトでは、MCP の入口 `ship-content/` を通すようにする（ほかの REST は止めたままでよい）。

## 2. 使う投稿タイプと状態

| 状態 | できること |
|---|---|
| 未検証 | 読み取りだけ（入力欄の構造・制作方針・記事） |
| 試験中 | 下書きの作成・修正を試す。作った下書き・写真に試験の印が付き、`wp ship-content-mcp cleanup-tests --yes` で片付けられる |
| 試験合格・稼働 | 下書きの作成・修正ができる。**このときの入力欄の構造を記録し、その後に構造が変わったら、確かめ直すまで書き込みを止める**（ACF-003） |

- 最初は1つ（例：施工事例）だけを使う。ほかの投稿タイプは、既存の記事・入力欄・表示を確かめてから、未検証 → 試験中 → 試験合格の順に進める。
- ACF の入力欄を変えたら、「診断」の「確かめた構造」が赤になる。AI で試し、表示を確かめてから、基本設定の「いまの構造を確かめ直した」にチェックを入れて保存する。
- 固定ページ・メディア・内部の投稿タイプは、設定にかかわらず使えない。

## 3. PM のユーザーと鍵

1. 「ユーザー → 新規追加」で、PM ごとに権限グループ「Content MCP Operator」のユーザーを作る（投稿の編集などの権限は付けない。付けると MCP で使えなくなる）。パスワードは使わない（ログインしない）。
2. PM から公開鍵を受け取り、「端末の鍵」で登録する。表示された接続の情報（入口・鍵 ID・サイトの公開鍵）を PM に伝える。
3. 端末をなくした・担当が替わったときは、その鍵を「止める」。

HTTPS のサイトでは、Application Password でも接続できる（HTTP のサイト・サーバーの Basic 認証があるサイトでは、端末の署名を使う）。

## 4. 制作方針の書き方

- 「サイト共通」と「投稿タイプ別」に、自然な文章で書く。入力欄の field key は書かなくてよい（構造が変わっても書き直さなくてよい）。
- AI は、方針と入力欄の選択肢（表示名）を照らして値を選ぶ。表示名と同じ言葉で書くと伝わりやすい（例：「施工後の写真は基本 PC 2カラム」）。
- 実際の AI での試験から、次も書いておくとよい：
  - アイキャッチにする写真（例：「アイキャッチは施工後の1枚目」）
  - 分類の選び方（例：「施工事例カテゴリは施工箇所から選ぶ」）
  - コンセプト（見出し・説明）の書き方と、材料がないときの扱い（例：「PM の依頼にないときは、施工内容から短くまとめる」または「空のままにする」）
  - 書いてはいけないこと（費用・工期の推測、お客様の名前・番地など）
- 「AI が読む内容の確認」で、AI に渡る文を確かめられる。変えると版が上がり、履歴に残る。

## 5. 写真

- JPEG・PNG・WebP だけ。上限は基本設定で変えられる（初期 20MB）。
- 位置情報などのメタデータは、初期設定で消える（向きは写真に反映してから消す）。
- **メディアの写真は、記事が下書きでも URL を知っていれば見られる。** 公開してよい写真だけを登録する運用にする。

## 6. 記録・片付け・止め方

- 「記録」：接続の拒否・ツールの実行・認証の失敗・管理の操作（本文・画像・パスワードは記録しない。90日で消える）。
- 試験の片付け：`wp ship-content-mcp cleanup-tests`（一覧）→ `--yes`（消す）。
- すぐ止める：基本設定で「MCP を受け付ける」を外す（または `wp ship-content-mcp disable`）。入口がなくなる。

## 7. WP-CLI

| コマンド | すること |
|---|---|
| `wp ship-content-mcp status` | 診断（対処つき） |
| `wp ship-content-mcp selftest` | 自己テスト（読み取り中心） |
| `wp ship-content-mcp enable` / `disable` | MCP を受け付ける・止める |
| `wp ship-content-mcp post-type <name> <off\|unverified\|testing\|tested\|active> [--reverify]` | 投稿タイプの使い方（試験合格・稼働で構造を記録） |
| `wp ship-content-mcp keys list\|add\|revoke` | 端末の鍵 |
| `wp ship-content-mcp cleanup-tests [--yes]` | 試験の下書き・写真・転送の片付け |
