許可した投稿タイプの下書きを、社内 PM の AI エージェントから MCP で作成・修正するためのプラグインです。

== Description ==

WordPress 公式の MCP Adapter（別プラグイン）の上で動く、自作の MCP サーバーです。
WordPress 側では AI を呼びません。公開・予約・削除・ACF の定義の変更はできません。

読み取り（投稿タイプ・制作方針・入力欄の構造・記事）、下書きの検証・作成・修正、写真の分割転送のツールがあります。

== Changelog ==

= 0.9.6 =
* 全部のツールに MCP の印 openWorldHint=false（このサイトの中だけ）を付けた。Codex で写真の分割転送が承認を待って止まっていたため。写真の転送と新しい下書きの作成は承認なしで動き、既存の下書きを直すときは今までどおり承認が要る。

= 0.9.5 =
* AI がツールを名前や説明で探すアプリ（Codex など）でも、写真の登録まで迷わないようにした（サーバーの案内・最初のツールの返事・誤りに、写真の登録の仕方とツールの名前を入れた。写真のツールの説明に英語の言葉を足した）。

= 0.9.4 =
* ブラウザで許可した接続のアクセストークンを、接続の期限（初期 90日）まで使えるようにした（トークンを延長しない AI のアプリ、たとえば Codex で、1時間ほどでつながらなくなっていたため）。止めればその場で使えなくなるのは同じ。
* 「AI に貼る文」に、前は使えていたのにつながらなくなったときの案内と、つながらないあいだも WordPress の管理画面やブラウザで代わりをしないことを足した。

= 0.9.3 =
* 管理画面に「使い方」タブ（管理者向け・PM 向けの取説、写真つき）。サイト名・入口の URL・期限の日数・設定の状態は、そのサイトの値を出す。PM 向けだけを印刷・PDF に保存して渡せる。

= 0.9.1 =
* つながらないとき、AI が原因を見分ける（管理者の設定か、PM の側か）。管理者が直すときだけ、PM に「管理者に送る文」を作る（秘密は入れない）。ツールの誤りに who_fixes（admin・pm・ai）と next_step を付けた。

= 0.9.0 =
* ブラウザで許可する接続（OAuth 2.1・PKCE）。管理者が招待コードを発行し、PM は秘密の入っていない文を AI に貼り、AI が開いたブラウザで招待コードを入れて許可する。トークンなどの秘密が AI の会話に入らない。

= 0.8.2 =
* トークンの発行の欄で、MCP 用のユーザー（mcp-operator）がすでにいれば、それを選んでおく（押すたびにユーザーが増えないように）。

= 0.8.1 =
* 発行したときに出すものを「AI に貼る文」1つにまとめた（Claude Code・Codex など、AI が自分で MCP の設定に登録する）。コマンドは「自分で設定するとき」に折りたたんだ。

= 0.8.0 =
* トークン：管理画面で発行し、Claude Code・Codex などの MCP の設定に入れるだけでつながる（中継プログラム不要）。デモサイトで発行すれば、コピーしたサイトでも同じトークンが使える。写真はアップロード用 URL に AI が curl で送る。公開の前の片付け（すべて止める）と、削除時のデータの後片付け。

= 0.7.0 =
* Claude デスクトップアプリ（チャット）用の拡張機能（.mcpb）を、管理画面からサイトごとにダウンロードできる。PM は開いて接続コードを貼るだけ（Node.js 不要）。ほかの AI 向けの設定の表示。

= 0.6.0 =
* 接続コード：管理者が管理画面（または WP-CLI）で発行し、PM はコピーして Claude に一文を貼るだけで設定できる。中継プログラムに setup を追加。

= 0.5.1 =
* 配布の記録（manifest）の直し。機能の変更はなし（更新の試験を兼ねる）。

= 0.5.0 =
* 最初の公開版。GitHub のリリースからの更新（Plugin Update Checker）、配布用 ZIP の検査、CI。

= 0.4.0-dev =
* 確かめた構造（構造が変わったら書き込みを止める）、診断の対処、WP-CLI の post-type、手順書。

= 0.3.0-dev =
* 写真の分割転送（位置情報などを消して登録）、制作方針の画面の仕上げ。

= 0.2.0-dev =

= 0.1.0-dev =
* 自作の MCP サーバー、読み取りのツール3つ、端末の署名による認証、管理画面（基本設定・制作方針・端末の鍵・診断・記録）。
