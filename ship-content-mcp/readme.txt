許可した投稿タイプの下書きを、社内 PM の AI エージェントから MCP で作成・修正するためのプラグインです。

== Description ==

WordPress 公式の MCP Adapter（別プラグイン）の上で動く、自作の MCP サーバーです。
WordPress 側では AI を呼びません。公開・予約・削除・ACF の定義の変更はできません。

現在は読み取りのツール（投稿タイプの一覧・制作方針・入力欄の構造）だけです。
