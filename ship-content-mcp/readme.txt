許可した投稿タイプの下書きを、社内の指示者の AI エージェントから MCP で作成・修正するためのプラグインです。

== Description ==

WordPress 公式の MCP Adapter（別プラグイン）の上で動く、自作の MCP サーバーです。
WordPress 側では AI を呼びません。公開・予約・削除・ACF の定義の変更はできません。

読み取り（投稿タイプ・制作方針・入力欄の構造・記事）、下書きの検証・作成・修正、分類の語の追加、写真の登録（アップロード用 URL・分割転送・URL からの取り込み）のツールがあります。

== Changelog ==

= 0.9.18 =
* 画面・AI への案内・使い方・手順書の「PM」を「指示者」にした（記事を依頼する人）。使い方のタブは「使い方（指示者向け）」。ツールの誤りの「誰が直すか」の値 pm は requester にした。

= 0.9.17 =
* 招待コードを発行するときに、許可した接続の期限を選べるようにした（1週間・1か月・3か月・6か月・1年・無期限。初期は基本設定の値）。WP-CLI は --grant-days（無期限は unlimited）。

= 0.9.16 =
* 「使い方」タブを「使い方（管理者向け）」「使い方（PM 向け）」の2つに分けた。取説の文には、サイト名・ドメイン・入口の URL を差し込まない（どの案件でも同じ文）。

= 0.9.15 =
* プラグインが新しくなる前に始めた AI の会話では、新しいツールが一覧に出ない。最初のツールの返事に、この版のツールの名前を入れ、足りなければ新しい会話でつなぎ直すよう案内する。

= 0.9.14 =
* 分類の語を足す add-term の、親と数の制限を外した（見出しになる親の語も足せる。24時間の上限はなし）。

= 0.9.13 =
* 記事に合う分類の語がないとき、AI が語を足せるツール（add-term）を足した。親の下にだけ足し、同じ語は作らず、似た語があれば候補を返す。基本設定の「AI が分類の語を足せる」で止められる。

= 0.9.12 =
* 最初のツール（list-post-types）の返事に、分類ごとの選べる語の一覧を足した。公開される分類が空のまま保存しようとしたら知らせる。

= 0.9.11 =
* 下書きの保存に、読んだ制作方針の版（policy_version）を必須にした（今の版でなければ保存せず、AI が読み直して送り直す）。保存した下書きに方針の版を記録し、記事を読むときに返す。

= 0.9.10 =
* 最初のツール（list-post-types）の返事に、制作方針を入れた（AI が制作に入る前に必ず受け取る）。下書きの確かめ・作成・修正の返事に、今の方針の版を付けた（途中で変わったら AI が読み直す）。

= 0.9.9 =
* 入力欄（ACF）の構造が、管理者の確かめた後に変わっても、書き込みを止めずに AI と診断に知らせるようにした（初期）。止めたいサイトは、基本設定の「入力欄が変わったら書き込みを止める」を入にする。

= 0.9.8 =
* 最初のツール（list-post-types）の返事に、写真の出どころ別の手順と、取り込めないときの案内（次の方法に移る・最後は写真なしで下書きを作って PM に伝える）を足した。

= 0.9.7 =
* 写真の URL から取り込むツール import-image-url（誰でも開ける http・https の URL だけ。サーバーの中・内側のネットワークの宛先は断る）。prepare-upload の返事に、分割ごとのコマンドと「base64 を書き写さない」注意（how_to_send）。

= 0.9.6 =
* 全部のツールに MCP の印 openWorldHint=false（このサイトの中だけ）を付けた。Codex で写真の分割転送が承認を待って止まっていたため。写真の転送と新しい下書きの作成は承認なしで動き、既存の下書きを直すときは今までどおり承認が要る。

= 0.9.5 =
* AI がツールを名前や説明で探すアプリ（Codex など）でも、写真の登録まで迷わないようにした（サーバーの案内・最初のツールの返事・誤りに、写真の登録の仕方とツールの名前を入れた。写真のツールの説明に英語の言葉を足した）。

= 0.9.4 =
* ブラウザで許可した接続のアクセストークンを、接続の期限（初期 90日）まで使えるようにした（トークンを延長しない AI のアプリ、たとえば Codex で、1時間ほどでつながらなくなっていたため）。止めればその場で使えなくなるのは同じ。
* 「AI に貼る文」に、前は使えていたのにつながらなくなったときの案内と、つながらないあいだも WordPress の管理画面やブラウザで代わりをしないことを足した。

= 0.9.3 =
* 管理画面に「使い方」タブ（管理者向け・PM 向けの取説、写真つき）。サイト名・入口の URL・期限の日数・設定の状態は、そのサイトの値を出す。PM 向けだけを印刷・PDF に保存して渡せる。

= 0.9.1 =
* つながらないとき、AI が原因を見分ける（管理者の設定か、PM の側か）。管理者が直すときだけ、PM に「管理者に送る文」を作る（秘密は入れない）。ツールの誤りに who_fixes（admin・pm・ai）と next_step を付けた。

= 0.9.0 =
* ブラウザで許可する接続（OAuth 2.1・PKCE）。管理者が招待コードを発行し、PM は秘密の入っていない文を AI に貼り、AI が開いたブラウザで招待コードを入れて許可する。トークンなどの秘密が AI の会話に入らない。

= 0.8.2 =
* トークンの発行の欄で、MCP 用のユーザー（mcp-operator）がすでにいれば、それを選んでおく（押すたびにユーザーが増えないように）。

= 0.8.1 =
* 発行したときに出すものを「AI に貼る文」1つにまとめた（Claude Code・Codex など、AI が自分で MCP の設定に登録する）。コマンドは「自分で設定するとき」に折りたたんだ。

= 0.8.0 =
* トークン：管理画面で発行し、Claude Code・Codex などの MCP の設定に入れるだけでつながる（中継プログラム不要）。デモサイトで発行すれば、コピーしたサイトでも同じトークンが使える。写真はアップロード用 URL に AI が curl で送る。公開の前の片付け（すべて止める）と、削除時のデータの後片付け。

= 0.6.0 =
